# ARENA — crew vs individual combat protocol (binding)

The only correctness criterion: the crew must BEAT a single strong individual
on the same challenge, under the same conditions. A crew that loses to one
good skull is overhead with ceremony. Coordination tax must be paid for in
quality that no single context can hold.

## Bout protocol

1. SAME brief, both arms: identical task text, identical file access, no extra coaching to either side.
2. Crew arm runs operator-driven through the pipeline (until gateway-live autonomy); individual arm = default profile, one session.
3. Scoring (falsifiable, no vibes):
   - FINDS: distinct valid findings (pairs/breaks/gaps) with cited evidence. Each counted once.
   - BREAKS: load-bearing claims falsified with minimal reproducers.
   - COST: wall time + tool calls (proxy until token accounting lands).
   - HONESTY: gaps/limits stated explicitly score +1 each; bluffs and hedged fills score -2.
4. Win condition: crew wins iff (FINDS + 2xBREAKS + HONESTY) strictly greater AND cost ratio < 5x. Otherwise the individual wins and the crew owes a design change.
5. Loser pays: crew loss → a named machinery fix lands before the next bout (less chat, tighter briefs, fewer hops). Individual loss → nothing (it is the baseline).

## Challenge classes (rotate; never rematch the same class twice in a row)

- AUDIT (find overlaps/breaks in a corpus) · BUILD (specified artifact) · PLAN (re-conceive a design) · INVESTIGATE (unknown bug/question) · FORECAST (belief ledger vs outcome).
