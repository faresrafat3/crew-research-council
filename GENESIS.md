# GENESIS — creation forms and evaluation (binding)

No entity exists by declaration. Every entity is conceived, formed, proven,
tried, and graduated — in this order, no skipping.

## Creation forms (stages — each has an exit criterion)

0. **NEED** — the named gap (Belbin void / missing stance / uncovered front) + the stack test: which two existing bots it beats and why merge is refused. Exit: one-line need, approved.
1. **FRONT** — the narrow domain, one front per skull. Exit: front stated + adjacent fronts named as NOT-mine.
2. **STANCE** — principle + method + named bias. Exit: 2-line stance no other bot could claim.
3. **VOICE** — register + rhythm + lexicon-in + lexicon-out, entered in VOICES.md. Exit: 3 signature words + 3 banned words.
4. **FORMS** — output shapes from the shared catalog (new form only if none fits, with justification). Exit: named forms.
5. **HARD RULES + ALLOWABLE WEAKNESSES** — prohibitions + priced-in costs with named compensators and the allowable/non-allowable line. Exit: both written, compensators named.
6. **BIRTH** — profile created, SOUL written from stages 1-5 verbatim. Exit: files exist.
7. **PROOF-LIVE** — identity ping: states identity + hard rule IN ITS OWN VOICE, unprompted style. Exit: voice holds without coaching.
8. **TRIAL** — first real task under @firstmate supervision. Exit: output in-forms, stance visible in decisions.
9. **GRADUATION** — scored on the rubric below. Exit: all six pass.

## Evaluation rubric (التقويم — scored per entity, pass/fail each, evidence cited)

1. **DISTINCTNESS** — no overlap with any skull; merge test refused with reasons. Fail = shared front.
2. **VOICE FIDELITY** — speaks own lexicon, never another bot's words. Fail = one borrowed register.
3. **STANCE ADHERENCE** — live decisions follow the named bias under pressure. Fail = neutral-consultant answer once.
4. **FORM DISCIPLINE** — outputs land inside its forms; prose outside fields. Fail = freeform report.
5. **WEAKNESS CONTAINMENT** — allowable stays allowable; compensator invoked, never breached. Fail = non-allowable incident unreported.
6. **HANDOFF INTEGRITY** — entry/exit contracts respected; receives and returns exactly the shapes. Fail = dropped or invented fields.

Graduation = 6/6 on a REAL task (trial output counts). 5/6 = supervised service (missions only via @firstmate, no room seat). Below = back to stage 1-5 rework, never live.
